Script for downloading and subsetting ERA5 reanalysis data

To use, create a copernicus account

Then create a file called cdsapi.rc including the two lines below and save it in the rood of this folder.  Get your api key from copernicus and paste it into the file.

`
url: https://cds.climate.copernicus.eu/api
key: **YOUR-API-KEY-HERE**
`
